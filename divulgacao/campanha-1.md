# Campanha 1: lotar o grupo do WhatsApp (teste de criativos)

## Estrutura

| Nível | Configuração |
|---|---|
| **Campanha** | Objetivo **Cadastros** (Leads). Nome: `Grupo WhatsApp - Teste criativos - Nov26` |
| **Conjunto** | Local da conversão: **Site**. Pixel: **Pixel Casa em Conta**. Evento: **Lead** |
| | Orçamento: **R$ 20 por dia** (no conjunto). Início: **25/11 às 00:00**, sem data de término |
| | Público: **Brasil**, 22 a 55 anos, todos os gêneros. Deixe o "Público Advantage+" ligado |
| | Posicionamentos: Instagram e Facebook (Feed, Stories e Reels). Desligue o Audience Network |
| **Anúncios** | 3 anúncios (abaixo), todos com a página **Casa em Conta** como identidade |
| | URL do site: `https://lpzueira.github.io/casaemconta/` |
| | Botão: **Saiba mais** |

Os vídeos não têm som. Na tela do anúncio dá para adicionar uma música da biblioteca da Meta, que é liberada para anúncios.

## Acompanhamento

- **Anote o número de membros do grupo** antes de começar e todo dia no mesmo horário.
- Espere **3 a 4 dias** antes de julgar. Depois, compare o **custo por resultado (Lead)** de cada anúncio.
- O anúncio mais caro pode ser pausado. Coloque a verba no melhor e teste um vídeo novo no lugar.
- Os comentários dos anúncios ficam na página Casa em Conta do Facebook. Responda com o link da página.
